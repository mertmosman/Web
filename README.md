# 🌐 Hakkımda Web Sitesi

Bu proje, sizin hakkınızda bilgi veren, kişisel bir “Hakkımda” web sitesi sunar. Ziyaretçilerinize kendinizi tanıtmak, yeteneklerinizi sergilemek ve iletişime geçmeyi kolaylaştırmak için modern web teknolojileri ile hazırlanmıştır.

---

## 📋 Ön Koşullar

Projeyi yerelde çalıştırabilmek için şu araçlara ihtiyacınız var:

- Bir web tarayıcısı (Chrome, Firefox, Edge vb.)
- (Opsiyonel) PHP backend kullanıyorsanız, çalıştırabileceğiniz bir yerel sunucu ortamı (örneğin: XAMPP, MAMP, WAMP)
- (Opsiyonel) Geliştirme kolaylığı için bir IDE (VS Code, PhpStorm vb.)

---

## 🛠️ Kullanılan Araçlar

- **HTML5 / CSS / JavaScript** – Temel yapı ve etkileşimler  
- **PHP** – Sunucu tarafı işlemleri  
- **Bootstrap / Tailwind** – Responsive stil frameworkleri  
- **VS Code / PhpStorm** – Kodlama ortamları
